# Kirirom-Vehicle - 车辆申请登记管理系统

## 📖 项目简介

**Kirirom-Vehicle** 是一个为企业或机构设计的车辆申请登记管理系统。

该项目通过微信小程序提供便捷的界面，让用户能够在线提交用车申请、预约车辆；同时为管理员提供强大的后台管理工具，包括：

* **申请审核**：实时查看并处理用户的报备申请。
* **数据同步**：支持批量导入（Excel / CSV）和导出数据功能。
* **用户管理**：管理驾驶员列表、用户权限及关联信息。
* **车辆维护**：动态更新车队状态、车型详情等基础信息。

---

## 🚀 核心功能模块

### 1. 用户端（Miniprogram）

#### 首页展示

直观展示当前可用的车辆信息或申请入口。

#### 申请流程

用户可填写详细的用车需求，包括时间、地点、用途等信息，系统自动进入审核流。

#### 详情查看

支持查看个人提交历史及报送单的状态更新。

---

### 2. 管理后台（Cloud Functions & Admin Panel）

#### 云函数逻辑层

* `submitApplication`：处理用户端发起的申请请求。
* `approveApplication`：后台审核通过或驳回相关业务。
* `importApplications` / `exportApplications`：支持大规模数据的批量导入与导出。
* `getDriverList` / `get_userList`：管理员获取并维护员工、驾驶员资料。

#### 后台管理功能

* **车辆更新**：快速通过后台修改车辆模型、载重及现有状态。
* **用户过滤与删除**：确保数据库内用户信息同步且准确。
* **文件处理逻辑**：自动生成并处理导出文件的相关清理任务，例如 `adminDeleteExportFile`。

## 🚀 快速开始

### 环境准备

1. 下载并安装微信开发者工具。
2. 确保已开通微信云开发能力。
3. 克隆仓库后，根据项目依赖情况执行：

```bash
npm install
```

如云函数目录下存在独立依赖，也需要进入对应云函数目录分别安装依赖。

---

## 部署步骤

### 1. 本地预览

1. 在微信开发者工具中打开项目。
2. 配置好云开发环境地址。
3. 确认 `project.config.json` 中的小程序 AppID、目录配置与实际项目一致。

### 2. 云函数部署

1. 进入 `cloudfunctions` 目录。
2. 根据具体云函数依赖情况执行：

```bash
npm install
```

3. 通过微信开发者工具菜单或命令行同步、上传并发布云函数至生产环境。

### 3. 真机调试

1. 使用微信开发者工具扫码登录。
2. 选择真机调试。
3. 在真实微信环境中测试申请提交、审核、数据读取、导入导出等核心流程。

## 📝 开发规范与注意事项

### API 调用

所有涉及数据库（Database）操作的功能，建议统一通过云函数（Cloud Functions）处理。

如需在小程序端直接调用，应结合当前运行环境进行判断，例如：

```javascript
wx.cloud.callFunction({
  name: 'submitApplication',
  data: {
    // application data
  }
})
```

### 权限控制

管理端相关 API 必须具备相应的鉴权逻辑，确保普通用户无法调用 `admin*` 开头或涉及审核、删除、导出等高权限操作的云函数。

建议重点控制以下功能权限：

* 审核申请
* 删除用户
* 导入数据
* 导出数据
* 删除导出文件
* 修改车辆基础信息
* 查看全部用户或驾驶员信息

### 文件路径

涉及导出文件的临时路径，建议使用当前标准的云存储规范。

导出文件应设置合理的清理机制，避免长期占用云存储空间，例如通过 `adminDeleteExportFile` 等云函数定期清理无效文件。
